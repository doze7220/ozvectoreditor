*   **index.html** : スタイルはCSSファイル分割せず`<style>`タグに内包する。フロートウィンドウ全体の非活性化は`.disabled`クラス（`pointer-events: none`）で表し、ボタン単体の押せない状態はHTMLの`disabled`属性と`.tool-btn:disabled`（半透明・`cursor: default`）で表す（両者を混用しない）。`.tool-btn`のホバー色は`:hover:not(:disabled)`で押せる状態のみに限る。各ボタンの`title`属性にショートカットキーを併記しており（例：`選択 (V)`、図形パレットは`SHAPE_TYPES`の並びに対応する数字）、`KeyboardShortcuts.js`の`SHORTCUT_BINDINGS`と手動で同期する必要がある。
    *   **取り消し・やり直しボタン** : コントロールパネルの削除ボタンの直後（倍率表示行の前）に、`.history-button-row`（`display: flex; gap: 8px`。内側の`.tool-btn`は`flex: 1`・中央揃え・`white-space: nowrap`）で`#history-undo`（`title="取り消し (Ctrl+Z)"`）と`#history-redo`（`title="やり直し (Ctrl+Y / Ctrl+Shift+Z)"`）を1行に横並びで置く。初期状態は`disabled`。
    *   **キャンバス名の表示と呼び出し口** : コントロールパネルの末尾（倍率表示行の後）に、開いているキャンバスの名前の表示`#canvas-name-display`（1行の省略表示。`main.js`の`syncCanvasNameDisplay()`が内容・`title`を設定）と、キャンバスパレットの呼び出し口`#launcher-canvas`（`📁 キャンバス`）をこの順に置く。
    *   **キャンバスパレット** : `#window-canvas-palette`（`.float-window`）を`#window-dev-panel`の前に静的に置き、`hidden`属性で初期非表示とする（開閉は`PaletteLauncher`）。内部は新規作成ボタン`#canvas-create`・ファイル操作の行`.canvas-file-row`（書き出し`#canvas-export`・開く`#canvas-open-file`・インポート`#canvas-import`の3ボタン。`display: flex`で1行に収める）・非表示（`hidden`）のファイル選択`<input type="file">`2つ（`#canvas-open-file-input`・`#canvas-import-file-input`。`accept=".json,application/json"`。どちらのボタンから開いたかの状態を持たずに済むよう2つ置く）・一覧`#canvas-list`（行の生成は`CanvasPalette`）・状態の文言`#canvas-notice`（初期`hidden`）・ファイル操作の通知の文言`#canvas-file-notice`（`#canvas-notice`の下。同じ`.canvas-notice`の見た目。初期`hidden`。互いに隠さず独立に表示）。`.canvas-notice`は区切りの無い長いファイル名でもはみ出さないよう`overflow-wrap: anywhere`を指定する。初期位置はコントロールパネルの左隣（`top: 16px; right: 252px`。コントロールパネル`right: 16px`＋幅220px＋間隔16px）。開いているキャンバスの行は`.tool-btn.active`と同じ配色で示す。行のボタンの押せない状態は`disabled`属性と`.tool-btn:disabled`で表す。
    *   **読み込み中の覆い要素** : `<canvas id="editor-canvas">`の直後に`#canvas-loading-cover`（文言「読み込み中…」）を静的に置き、`hidden`を付けずに表示状態で始める（`main.js`の実行前からキャンバスへのマウス入力を遮るため）。`main.js`の`syncLoadingCover()`が起動時の読み込み完了で`hidden`を付けて非表示にする。`z-index: 5`でキャンバス（`1`）より前面・フロートウィンドウ（`10`以上）より背面とし、コントロールパネル等は読み込み中も操作できる。`display: flex`が`hidden`属性の既定の非表示を上書きするため、`.canvas-loading-cover[hidden] { display: none; }`の指定が必須である。`main.js`の初期化が途中で失敗すると覆いが消えない（その場合はコンソールのエラーを確認する）。
    *   **図形選択パレットの位置** : `#window-shape-palette`の`top`は`440px`（コントロールパネルの下端との余白24px以上を確保するための固定値。自動配置はしない）。コントロールパネルの高さを変える場合は手動で再調整すること（ボタンの高さはフォント・絵文字の表示に依存する）。
    *   **図形選択パレットのボタン** : 各ボタンのidは`palette-${type}`（`type`は`SHAPE_TYPES`の値）の規則に従い、`PaletteController`が起動時にこの規則で照合・配線する。アイコン・表示名・`title`は静的記述である。パレット内では、図形種別ボタン以外の要素に`palette-`で始まるidを使わないこと（照合時に警告される）。
    *   **確認用ウィンドウ** : `#window-dev-panel`（`.float-window`）は`hidden`属性で初期非表示とし、`?dev`時のみ`main.js`が表示する。`.float-window`全体の`user-select: none`は変更せず、テキスト欄`#dev-json`と結果表示`#dev-result`に限って`user-select: text`を指定する。
    *   **フロートウィンドウの`×`ボタン** : `PaletteLauncher`の対応表に含まれる開閉式パレット（現状はキャンバスパレットのみ）の`×`だけが閉じる機能を持つ。それ以外のウィンドウ（コントロールパネル・図形選択パレット・確認用ウィンドウ）の`×`は見た目のみで、閉じる処理は配線されていない。
