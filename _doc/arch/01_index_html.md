*   **index.html**：スタイルはCSSファイル分割せず`<style>`タグに内包する。配置・見た目はマークアップとCSSコメントを正とする。
    *   **非活性の表現**：フロートウィンドウ全体の非活性化は`.disabled`クラス（`pointer-events: none`）、ボタン単体の押せない状態はHTMLの`disabled`属性と`.tool-btn:disabled`で表す。両者を混用しない。
    *   **ショートカットの表記**：各ボタンの`title`属性にショートカットキーを併記している（図形パレットは`SHAPE_TYPES`の並びに対応する数字）。`KeyboardShortcuts.js`の`SHORTCUT_BINDINGS`と手動で同期する必要がある。結合ボタン`#selection-join`の`title`は`(J)`を併記している。「重なり順」の4ボタンの`title`は`最前面へ (Home)`・`前へ (PageUp)`・`後ろへ (PageDown)`・`最背面へ (End)`。
    *   **選択操作ボタンの行**：コントロールパネルの「削除」`#selection-delete`と「結合」`#selection-join`は`.selection-button-row`で1行に横並びにしている（コントロールパネルの高さを増やさないため。図形パレットとの余白は`#window-shape-palette`の項のとおり）。結合ボタンは`disabled`で始まり、`main.js`の`syncJoinButtonState`が同期する。
    *   **読み込み中の覆い要素**：`#canvas-loading-cover`は`hidden`を付けずに表示状態で始める（`main.js`の実行前からキャンバスへのマウス入力を遮るため）。`.canvas-loading-cover[hidden] { display: none; }`の指定は必須。`main.js`の初期化が途中で失敗すると覆いが消えない（その場合はコンソールのエラーを確認する）。
    *   **図形選択パレットの位置**：`#window-shape-palette`の`top`はコントロールパネルの下端との余白24px以上を確保するための固定値。自動配置はしない。コントロールパネルの高さを変える場合は手動で再調整する（ボタンの高さはフォント・絵文字の表示に依存する）。
    *   **図形選択パレットのボタン**：idは`palette-${type}`（`type`は`SHAPE_TYPES`の値）。`PaletteController`が起動時にこの規則で照合・配線する。アイコン・表示名・`title`は静的記述。パレット内では、図形種別ボタン以外の要素に`palette-`で始まるidを使わない（照合時に警告される）。
    *   **キャンバスパレットのボタンの並び**：「＋ 新規作成」・「出力（作業ファイル）」（`#canvas-export`）・「出力（エンジン用）」（`#canvas-export-sprite`）は1行に1つずつ縦に並べ、「開く」「インポート」だけを`.canvas-file-row`で横並びにする（出力の2ボタンは文字だけで約247pxとなり、パレットの内側の幅216pxに1行で収まらないため）。`title`にダウンロードされるファイルの拡張子を書く。
    *   **キャンバスパレットのファイル選択**：非表示の`<input type="file">`を「開く」用（`#canvas-open-file-input`）と「インポート」用（`#canvas-import-file-input`）の2つ置く。どちらのボタンから開いたかの状態を持たずに済むため。1つにまとめない。`accept=".json,.js,application/json,text/javascript"`は拡張子の末尾で照合するため`.ozve.json`も選べ、スプライトのJSも選べる（`.json`は作業データファイルのため外さない。変更しない。2章「エディタで開くときの規則」）。ボタンの`title`に作業ファイル（.ozve.json）とスプライト（.js）を書く。
    *   **プロパティパネル**：`#window-property-panel`は静的に置き（`hidden`なし＝常に表示。`WindowManager`は起動時にDOMにある`.float-window`だけを検知するため）、見出しはタイトル「プロパティ」のみで`×`は無い。`.disabled`は使わず（操作モードにかかわらず常に操作できる）、塗りの欄の無効表示は各`input`の`disabled`属性で行う（上の「非活性の表現」と混用しない）。初期位置は`top: 16px; right: 508px; width: 220px`（開いた状態のキャンバスパレットの左隣。位置の根拠はCSSコメント）。`checked`・`value`等の初期値は書かない（起動時に`main.js`が1回描画する。既定値を二重に書かないため）。プロパティパネルの中では太さの欄のみ`user-select: text`（ほかに`?dev`の確認用ウィンドウの欄にも付く。`.float-window`の`user-select: none`は変えない）。
    *   **プロパティパネルの2段構成**：本体に段ごとの`<section class="property-section">`と見出し`<h3 class="property-section-title">`を置く（現状は`#property-shape-section`「図形」と`#property-order-section`「重なり順」の2段）。段のidは段ごとの接頭辞（「図形」の段は`property-`、「重なり順」の段は`order-`）で重複させない。「重なり順」の段の4ボタンは`.order-button-grid`で2×2に並べ、`disabled`で始まり、`main.js`の`syncPropertyOrderSection`が同期する（入力欄の「初期値は書かない」の例外ではなく、結合ボタンと同じ扱い）。パネルの高さ・下端の見積もりはCSSコメントが正。段を足すときは新しい`<section>`を足すだけで既存の段は変えない（段の足し方は`PROJECT_ARCHITECTURE.md`3章13.）。
    *   **確認用ウィンドウ**：`#window-dev-panel`は`hidden`で初期非表示。`?dev`時のみ`main.js`が表示する。
    *   **フロートウィンドウの`×`ボタン**：コントロールパネル・図形選択パレット・プロパティパネルには`×`が無い（見出しはタイトルのみ。`.window-header`の`min-height`で他のウィンドウと高さをそろえる）。`PaletteLauncher`の対応表に含まれる開閉式パレット（現状はキャンバスパレットのみ）の`×`は閉じ、呼び出し口で開き直せる。`?dev`の確認用ウィンドウの`×`は`DevPanel`が配線して閉じる（開き直す手段は無く、再読み込みで再表示）。
