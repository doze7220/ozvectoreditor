*   **index.html**：スタイルはCSSファイル分割せず`<style>`タグに内包する。配置・見た目はマークアップとCSSコメントを正とする。
    *   **画面の領域**：上端にツールバー（`#toolbar`）、下端にステータスバー（`#status-bar`）、その間にキャンバスの領域、フロートウィンドウのツールパレット等。寸法は`<style>`先頭の`:root`のカスタムプロパティ（`--toolbar-height`・`--statusbar-height`・`--canvas-area-*`・`--float-window-*`）が唯一の定義箇所。キャンバス（`#editor-canvas`）と読み込み中の覆い要素は、まとめた1つのCSSルールで同じキャンバスの領域に置く（`<canvas>`は置換要素で`left`・`right`の両指定では伸びないため、`width`/`height`をCSSの変数で明示する）。07-03で定規を足すときに直すのは`--canvas-area-top`と`--canvas-area-left`の2行で、幅・高さ・フロートウィンドウの既定の位置の基準はそれに追従する。**キャンバスに枠線・内側の余白を付けない**（`InputTracker.getScreenCoordinate`の`clientWidth / rect.width`の比が1でなくなり、座標がずれるため。領域を狭めるときは`:root`で行う）。重なりの順（`z-index`）：キャンバス1 → 覆い要素5 → ツールバー・ステータスバー8 → フロートウィンドウ10以上（`WindowManager`の最前面化で増える一方）。ブラウザのウィンドウの大きさの変化は既存の`resize` → `renderCurrentState`の経路で足りる。
    *   **ツールバー・ステータスバー**：固定の要素で、フロートウィンドウではない（`WindowManager`の管理対象外。イベント遮断も不要。キャンバスの子ではない兄弟要素のため、その上の押下・クリックはキャンバスの操作にならない）。高さ固定・1行（`flex-wrap: nowrap; overflow: hidden`）で、収まらない右側の項目は画面の外へ切れる（折り返し・横スクロール・省略メニューは無い。ステータスバーのキャンバス名だけは先に`…`で省略される）。`user-select: none`。項目はまとまりごとに置く：ツールバーは`<div class="toolbar-group">`、ステータスバーは左右の`.status-bar-side`の中に`<div class="status-bar-group">`。まとまりの区切りは隣接セレクタ（`.toolbar-group + .toolbar-group`・`.status-bar-group + .status-bar-group`）の`border-left`で付け、区切りの要素は置かない。項目を足すときはまとまりを足すだけで既存のまとまりを変えない。保っているid（`main.js`が`getElementById`で解決する）：`#launcher-canvas`・`#history-undo`・`#history-redo`・`#selection-delete`・`#selection-join`（ツールバー）、`#canvas-name-display`・`#view-zoom-display`・`#view-reset`（ステータスバー）。
    *   **ボタンの見た目**：ツールバー・ステータスバー・ツールパレットのボタンはアイコンのみ（`class="tool-btn icon-btn"`。文字のラベルは付けない）。アイコンは`index.html`のそのボタンの中身の1か所だけに書く（JSはボタンの中身を書き換えず、CSSの`content`で重ねない）。説明とショートカットは`title`に書く。`.icon-btn`は`.tool-btn`のルールの後に置き、大きさと中央寄せだけを上書きする（押し込み・押せない・ホバーの見た目は`.tool-btn`のルールをそのまま使う）。
    *   **非活性の表現**：ボタン単体の押せない状態はHTMLの`disabled`属性と`.tool-btn:disabled`のみで表す。フロートウィンドウ全体を非活性にする`.disabled`クラスは以前あったがPhase 07-01で削除した（CSSのルールごとなくなった。ツールパレットは常に押せ、プロパティパネルも常に操作できる）。
    *   **ショートカットの表記**：各ボタンの`title`属性にショートカットキーを併記している（ツールパレットの図形のボタンは`SHAPE_TYPES`の並びに対応する数字）。`KeyboardShortcuts.js`の`SHORTCUT_BINDINGS`と手動で同期する必要がある。結合ボタン`#selection-join`の`title`は`(J)`を併記している。「重なり順」の4ボタンの`title`は`最前面へ (Home)`・`前へ (PageUp)`・`後ろへ (PageDown)`・`最背面へ (End)`。結合ボタンは`disabled`で始まり、`main.js`の`syncJoinButtonState`が同期する。
    *   **読み込み中の覆い要素**：`#canvas-loading-cover`は`hidden`を付けずに表示状態で始める（`main.js`の実行前からキャンバスへのマウス入力を遮るため）。キャンバスの領域だけを覆い、ツールバー・ステータスバー（`z-index`が上）は読み込み中も押せる。`.canvas-loading-cover[hidden] { display: none; }`の指定は必須。`main.js`の初期化が途中で失敗すると覆いが消えない（その場合はコンソールのエラーを確認する）。
    *   **ツールパレット**：`#window-tool-palette`は静的に置き（`hidden`なし＝常に表示。`WindowManager`は起動時にDOMにある`.float-window`だけを検知するため）、`×`は無い。見出し（`.window-header`）に文字は置かない（幅44pxに収まらないため。ドラッグ用）。ボタンのidは`tool-${toolId}`（`toolId`は`ToolRules`の`TOOL_IDS`の値＝`select`・`pan`と`SHAPE_TYPES`の値）。`ToolPalette`が起動時にこの規則で照合・配線する。パレット内では、ツールのボタン以外の要素に`tool-`で始まるidを使わない（照合時に警告される）。区切りは`.tool-palette-group`の隣接セレクタ。起動時は`#tool-select`だけに`index.html`で`active`を付ける（`InputTracker`の初期モードは選択で、JSの読み込み前も押し込みを見せるため。起動時の`applyMode(OperationMode.SELECT)`が同じ結果を同期する）。旧id`#mode-select`・`#mode-create`・`#mode-pan`・`#palette-${type}`は無い。
    *   **キャンバスパレットのボタンの並び**：「＋ 新規作成」・「出力（作業ファイル）」（`#canvas-export`）・「出力（エンジン用）」（`#canvas-export-sprite`）は1行に1つずつ縦に並べ、「開く」「インポート」だけを`.canvas-file-row`で横並びにする（出力の2ボタンは文字だけで約247pxとなり、パレットの内側の幅216pxに1行で収まらないため）。`title`にダウンロードされるファイルの拡張子を書く。
    *   **キャンバスパレットのファイル選択**：非表示の`<input type="file">`を「開く」用（`#canvas-open-file-input`）と「インポート」用（`#canvas-import-file-input`）の2つ置く。どちらのボタンから開いたかの状態を持たずに済むため。1つにまとめない。`accept=".json,.js,application/json,text/javascript"`は拡張子の末尾で照合するため`.ozve.json`も選べ、スプライトのJSも選べる（`.json`は作業データファイルのため外さない。変更しない。2章「エディタで開くときの規則」）。ボタンの`title`に作業ファイル（.ozve.json）とスプライト（.js）を書く。
    *   **プロパティパネル**：`#window-property-panel`は静的に置き（`hidden`なし＝常に表示。`WindowManager`は起動時にDOMにある`.float-window`だけを検知するため）、見出しはタイトル「プロパティ」のみで`×`は無い。`.disabled`は使わず（操作モードにかかわらず常に操作できる。`.disabled`自体がもう無い）、塗りの欄の無効表示は各`input`の`disabled`属性で行う（上の「非活性の表現」と混用しない）。初期位置は`top: var(--float-window-top); right: 258px; width: 220px`（開いた状態のキャンバスパレットの左隣。位置の根拠はCSSコメント）。`checked`・`value`等の初期値は書かない（起動時に`main.js`が1回描画する。既定値を二重に書かないため）。プロパティパネルの中では太さの欄のみ`user-select: text`（ほかに`?dev`の確認用ウィンドウの欄にも付く。`.float-window`の`user-select: none`は変えない）。
    *   **プロパティパネルの2段構成**：本体に段ごとの`<section class="property-section">`と見出し`<h3 class="property-section-title">`を置く（現状は`#property-shape-section`「図形」と`#property-order-section`「重なり順」の2段）。段のidは段ごとの接頭辞（「図形」の段は`property-`、「重なり順」の段は`order-`）で重複させない。「重なり順」の段の4ボタンは`.order-button-grid`で2×2に並べ、`disabled`で始まり、`main.js`の`syncPropertyOrderSection`が同期する（入力欄の「初期値は書かない」の例外ではなく、結合ボタンと同じ扱い）。パネルの高さ・下端の見積もりはCSSコメントが正。段を足すときは新しい`<section>`を足すだけで既存の段は変えない（段の足し方は`PROJECT_ARCHITECTURE.md`3章13.）。
    *   **確認用ウィンドウ**：`#window-dev-panel`は`hidden`で初期非表示。`?dev`時のみ`main.js`が表示する。
    *   **ウィンドウの既定の位置**：ツールパレットは左上、キャンバスパレットは右上、プロパティパネルはキャンバスパレットの左隣、`?dev`の確認用ウィンドウはツールパレットの右隣。いずれも上端はツールバーの下（`--float-window-top`）。互いに重ならない根拠の数値（幅・画面幅の条件）は各ルールのCSSコメントを正とする（ここに重ねて書かない）。位置・表示状態は保存しない。
    *   **フロートウィンドウの`×`ボタン**：ツールパレット・プロパティパネルには`×`が無い（プロパティパネルの見出しはタイトルのみ。`.window-header`の`min-height`で他のウィンドウと高さをそろえる）。`PaletteLauncher`の対応表に含まれる開閉式パレット（現状はキャンバスパレットのみ）の`×`は閉じ、呼び出し口（ツールバーの`#launcher-canvas`）で開き直せる。`?dev`の確認用ウィンドウの`×`は`DevPanel`が配線して閉じる（開き直す手段は無く、再読み込みで再表示）。
