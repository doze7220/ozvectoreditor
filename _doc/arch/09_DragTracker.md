*   **DragTracker.js**：マウスボタン押下から解放までの1回のドラッグ操作のライフサイクル（開始ボタン・移動量閾値の判定、`window`へのcapture購読による追従/終了検知、blur時の中断、終了直後のclick抑止）を担う。
    *   **公開メソッド**：`begin`・`isActive`・`hasMoved`・`cancel`・`consumeSuppressedClick`・`clearSuppressedClick`。
    *   **`cancel({ suppressClick = false } = {})`**（Phase 10-01。省ける引数）：セッションが無ければ何もしない（従来どおり）。`suppressClick`が真で、中断したセッションが左ボタン（`button === 0`）なら、click抑止フラグを下ろさずに立てる（中断の後に左ボタンを離したときの`click`を1回無視する。式は`suppressClick && button === 0`の1つ）。省いたとき（blur・`setMode`・`abortOngoingOperation`の経路）と左以外のボタンは従来どおり下ろす（blurの後に`click`は来ないため）。`click`が来なかった残りは次の押下の`clearSuppressedClick()`で消える（今の約束）。呼び出し元は`InputTracker.cancelDraftOrClearSelection`の(1)（拡大縮小のドラッグ中の`Esc`。3章25.）だけで、`#handleWindowBlur`は引数なしの`cancel()`のまま。`window`購読に依存するためテストは置かない。
    *   **知らないこと**：ドラッグの意味（パン・範囲選択等）。`InputTracker`・`VectorModel`・`ViewTransform`・canvasをimport/参照しない。依存方向は`InputTracker`→`DragTracker`の一方向。スクリーン座標取得関数のみ注入される。
    *   **契約**：座標はすべてスクリーン座標。`threshold > 0`では初回`onMove`の`prevScreen`は閾値超過直前の`mousemove`の位置で、押下点とは限らない（累積移動量が必要な呼び出し側は押下時点の座標を自前で記憶する）。
