*   **InsertTargetRules.js**：新しい図形が入る場所を決める「描き込む先」の決まり方と、一覧で印に出す描き込む先・貼り付けと複製の入る場所の規則を、状態を持たない関数として提供する（Phase 11-03で新設。Phase 11-04bで、図形のidだけの持ち方から場所の値（`ItemPlaceRules`＝`62_ItemPlaceRules.md`）へ書き直した。流れは`PROJECT_ARCHITECTURE.md`2章・3章28.）。
    *   **公開**：`resolveNextInsertTarget({ previousItems, items, selectedIds, selectedGroupIds, target })`・`resolveRowInsertTarget(items, id)`・`isSameInsertTarget(a, b)`・`resolvePastePlace({ target, copiedGroupIds })`・`resolveDuplicatePlace(unitIds)`・`resolveInsertMark({ selectedCount, target })`と、typedef`InsertTarget`（`ItemPlace`のうち`'above'`・`'inside'`・`'bottom'`のいずれか。`'below'`にはならない）。旧`resolveInsertTarget`・`resolveInsertMarkId`は消した。
    *   **描き込む先の3つの形**：`{ above, 図形またはフォルダのid }`（その行のすぐ上へ入る）・`{ inside, フォルダのid }`（そのフォルダの中の一番上）・`{ bottom, フォルダのid }`（そのフォルダの中の一番下。`id`が`null`ならいちばん外側の一番下）。無し＝`null`（いちばん外側の一番上＝最前面）。
    *   **`resolveNextInsertTarget`**：変わった後の描き込む先（場所または`null`）を決める。`previousItems`＝変わる前の入れ子、`items`＝変わった後の入れ子、`selectedIds`・`selectedGroupIds`＝変わった後の選択（`Set`。`selectedGroupIds`は不変条件を通した後の値）、`target`＝候補。上から順に、最初に当たったものを返す。(1) 選んでいるまとまり（`resolveSelectedUnitIds`）が1つ以上 → 一番上のもの（結果の最後）を`resolveRowInsertTarget`に渡した値（図形なら`{ above, id }`、フォルダなら`{ inside, id }`）／(2) `target`が`null` → `null`／(3) `target`が今も有効 → 同じ内容の値（有効＝`above`は`id`のアイテムがある、`inside`と`bottom`（`id`あり）は`id`のフォルダがある、`{ bottom, null }`は`items`に1つ以上ある）／(4) 無くなった → `previousItems`での**元の場所**から求める（非公開`resolveVanishedTarget`。`inside`・`bottom`はそのフォルダの行が無くなったものとして扱う）：`findItemLocation(previousItems, target.id)`で元の並びを見つけ、その`parentId`が`null`か`items`にそのフォルダがあれば、元の並びを`index − 1`から0へたどり、`items`で**同じフォルダ（`parentId`が同じ）に残っている**最初のもののidの`{ above, id }`（フォルダでも`above`）。無ければ、いちばん外側なら`items`が空のとき`null`・そうでなければ`{ bottom, null }`、フォルダなら`{ bottom, parentId }`。元のフォルダも無ければ、さらにその元の場所へさかのぼる。元の場所が分からなければ`null`。これにより選んでいるまとまりが1つ以上あれば、描き込む先は必ず「選んでいるまとまりの一番上の行」で、選択と食い違う状態を作れない。引数を書き換えない。`items`のフォルダかどうかは`kind`で見る。
    *   **`resolveRowInsertTarget(items, id)`**：図形なら`{ above, id }`、フォルダなら`{ inside, id }`、無ければ`null`（描くツールで行を押したとき＝`VectorModel.setInsertTarget`。まとまりの一番上から決めるのも同じ関数で、規則を二重に書かない）。**`isSameInsertTarget(a, b)`**：どちらも`null`、または`kind`と`id`が同じか。
    *   **`resolvePastePlace({ target, copiedGroupIds })`**：貼り付けの入る場所。`target`が`inside`で、その`id`が`copiedGroupIds`（`Set`。`ClipboardController`の「自分のコピー」のフォルダのid）にあれば`{ above, その id }`（コピーしたフォルダの中へ入り込まず、すぐ上へ重なる）、そうでなければ`target`（`null`もそのまま）。**`resolveDuplicatePlace(unitIds)`**：複製の入る場所。まとまりが空なら`null`、そうでなければ`{ above, 最後のid }`（まとまりの一番上のもののすぐ上）。
    *   **`resolveInsertMark({ selectedCount, target })`**：一覧で印に出す描き込む先。`selectedCount`（選ばれている図形の数＋選んでいるフォルダの数）が1以上なら`null`（選ばれた行の見た目が優先）、そうでなければ`target ?? null`。印の割り当て（行・線・見えない行の印）は`ItemRowRules.resolveRowViews`（`61_ItemRowRules.md`）。
    *   **読むもの**：渡された入れ子の`kind`・`itemIdOf`の結果・選択の`Set`・場所の値だけ。importは`ItemTreeRules`（`ITEM_KIND`）・`GroupTreeRules`（`itemIdOf`）・`GroupSelectionRules`（`resolveSelectedUnitIds`）・`ItemPlaceRules`（`PLACE_KIND`・`findItemLocation`）のみ。
    *   **知らないこと**：DOM・`VectorModel`・図形・操作モード・履歴。状態を持たない。保存しない。
    *   **使う側**：`core/VectorModel`（`#applyState`が書き込みのたびに`resolveNextInsertTarget`を呼ぶ。`setInsertTarget`が`resolveRowInsertTarget`・`isSameInsertTarget`を使う。状態を持つクラスが規則をimportする向き）、`wiring/ItemListWiring`（`sync`が`resolveInsertMark`で印を決める）、`edit/ClipboardController`（`resolvePastePlace`・`resolveDuplicatePlace`。`edit → core`の例外）。
    *   **置き場所の理由**：描き込む先の決まり方の唯一の定義箇所にするため、また`node --test`で確かめるため、状態を持たない関数として`core/`に置いた（`VectorModel`は規則を知らず持ち主であるだけ）。貼り付け・複製の入る場所も、描き込む先の言葉（場所）で決まるためここに置いた。
    *   **テスト**：`test/core/InsertTargetRules.test.js`（46件。`resolveInsertMark`・`resolveNextInsertTarget`（選択・そのまま・まとまり・`inside`と`bottom`・元の場所＝同じフォルダの下の行／フォルダの外へ移った行を数えない／フォルダごと消えた／空になった）・`resolveRowInsertTarget`・`isSameInsertTarget`・`resolvePastePlace`・`resolveDuplicatePlace`。`_doc/arch/16_test.md`）。
