*   **CursorShapeRules.js**：操作モード・入力状態・当たり分類から、キャンバスに適用すべきCSSの`cursor`値を決める規則（カーソルの形の判定表）を、状態を持たない関数として提供する（Phase 08-01で`InputTracker`の`#resolveCursor`から切り出して新設。判定の順序・比較条件・結果の文字列は移動前と同じ）。
    *   **公開**：`resolveCursorShape(input)` → `'grabbing'`・`'grab'`・`'crosshair'`・`'cell'`・`'move'`・`'pointer'`・`'default'`のいずれかと、typedef`CursorShapeInput`（`isPanning`・`isSpacePressed`・`isLeftDragState`・`mode`・`state`・`isPickingShape`（関数）・`hit`（`PointHit`または`null`）・`isSelected`（関数）の8項目）。
    *   **判定の表**（この順に判定する。正本はJSDoc）：(0a)パンのドラッグ中 → `'grabbing'`、(0b)`Space`押下中かつ左ドラッグ状態（`DRAGGING_HANDLE`・`MOVING_SELECTION`・`MARQUEE_SELECTING`）でない → `'grab'`、(1)図形作成モード → `'crosshair'`（作成途中を含む）、(2)キャンバス移動モード → `'grab'`、(3)選択モード以外のモード → `'default'`（将来のモード追加時の既定値）、(3a)`isPickingShape()`が真（クリックした図形を外へ渡す待ち受け中） → `'cell'`、(4)`DRAGGING_HANDLE`・`MOVING_SELECTION` → `'move'`、(5)`MARQUEE_SELECTING` → `'default'`、(6)`hit === null`（座標不明） → `'default'`、(7)`hit.handle`あり → `'move'`、(8)`hit.bodyId`が選択集合内 → `'move'`、(9)それ以外の`hit.bodyId` → `'pointer'`、(10)それ以外 → `'default'`。(3a)は(3)の後・(4)の前のため、パン中・`Space`押下中の`'grabbing'`・`'grab'`が優先される。
    *   **読むもの**：引数の`input`のみ（書き換えない）。importは`core/InputModes`の`InputState`・`OperationMode`だけ。`PointHit`は型参照（JSDocの`import()`）のみで`import`文は書かない。**`isPickingShape`・`isSelected`は値（`boolean`）ではなく関数で受ける**：呼び出し元の短絡評価（`isPickingShape()`は選択モードのときだけ、`isSelected()`は本体に当たったときだけ呼ぶ）を保ち、呼び出しの回数を移動前と変えないため（値で受けると、今は呼ばれない場面でも`styleEyedropper.isPicking()`・`model.isSelected()`が呼ばれる。どちらも副作用のない照会だが、`main.js`の生成順の制約の説明（`_doc/arch/02_main.md`）とも食い違う）。
    *   **使う側**：`core/InputTracker`の`#updateCursor`のみ（現在の状態から`CursorShapeInput`を作り、戻り値を`canvas.style.cursor`へ入れる。`isPickingShape`・`isSelected`はアロー関数で渡す。`#updateCursor`の呼び出し箇所・引数は移動前と同じ）。`#isLeftDragState()`は`InputTracker`に残る。
    *   **知らないこと**：DOM（`canvas.style`への適用は`InputTracker`が担う）・`InputTracker`のインスタンス・当たり分類の計算（結果`hit`を受け取るだけ）・スポイト・`VectorModel`・修飾キー（ホバー・カーソルは`Ctrl`で変えない＝2026-11-14 発注者の決定）。
    *   **置き場所の理由**：判定表を`node --test`で確かめるため。`PointHitRules`と同じ形（`InputTracker`だけが使う状態のない規則）。`InputTracker`の再分離（状態の所有者設計）ではない。
