*   **VectorModel.js**：描画データ（Shape配列）と、選択集合・ホバー状態・作成中図形・選択矩形・吸い付きの表示の点・新しく描く図形のスタイル（直前に使った値）を保持する単一の真実（SSOT）。
    *   **公開メソッド**：`getShapes`・`replaceAllShapes`・`addShapesWithNewIds`・`replaceShape`・`reorderShapes`・`deleteShapes`・`updateVertex`・`moveShapes`・`updateShapeStyles`／`getNewShapeStyle`・`updateNewShapeStyle`／`setSelection`・`clearSelection`・`getSelectedIds`・`isSelected`／`setHovered`・`clearHovered`・`getHoveredId`／`setSelectionRect`・`clearSelectionRect`・`getSelectionRect`／`setSnapPoint`・`clearSnapPoint`・`getSnapPoint`／`startDraft`・`updateDraft`・`commitDraft`・`cancelDraft`・`getDraftShape`／`onChange`／`addShape`（使わない。理由はJSDoc）。
    *   **吸い付きの表示の点**：ワールド座標の1点（表示専用。保存・履歴の対象外）。`setSnapPoint`は同じ座標の再設定では通知せず、`clearSnapPoint`は表示中のときだけ通知する。`getSnapPoint`はコピーを返す。`replaceAllShapes`は選択集合・ホバー・作成中の図形・選択矩形とともにこの点も消す（通知は1回のまま）。設定・消去は`InputTracker`（3章12.）。
    *   **`replaceShape`**：指定idの図形の位置へ新しい図形を入れ、指定の図形を除く（通知は1回）。`select`が真（既定）なら結果の図形だけを選択し、偽なら選択集合を作り直さず消えたidだけを外す。`keepId`が真なら指定idを引き継ぎ、偽なら`#issueId()`で新しいidを採番する。呼び出し元は`PathJoiner`（`select`は既定の真）と`EndpointSnapper`（描き足しは`select: false`、ハンドルのドラッグでの結合は`select: true`）。`select`が真のとき選択モードであることは呼び出し側の保証（偽なら作成モードでも選択集合の不変条件を崩さない）。
    *   **`reorderShapes(orderedIds)`**：現在の全図形のidをちょうど1回ずつ並べた配列（先頭＝最も奥）で新しい並びを受け取る。配列でない・要素数が違う・現存しないid・重複idは`console.warn`して何もせず`false`。idから現在のインスタンスを引いて新配列を作り、全位置で同じインスタンスなら（警告・通知なしで）`false`。それ以外は`#shapes`を置き換えて通知を1回出し`true`。触れない状態：選択集合（`getSelectedIds`の返す順は新しい並びに従う）・ホバー・作成中の図形・選択矩形・吸い付きの表示の点・直前に使った値・idの採番・図形インスタンスの中身。履歴の記録は呼び出し側の責務。呼び出し元は`ShapeOrderEditor`のみ（図形の一覧のPhaseで一覧のドラッグからも使う見込み）。操作の種類（最前面へ等）を受け取らない理由：並べ替えの規則を`core/`へ持ち込まず、任意の並びを同じ操作で受けるため（規則は`edit/ShapeOrderRules`の1か所）。
    *   **新しく描く図形のスタイル（直前に使った値）**（2章）：非公開の`#newShapeStyle`（`NewShapeStyle`）。`getNewShapeStyle()`はコピーを返す。`updateNewShapeStyle(patch)`は5つのキー（自身のプロパティとして持つもの）だけを上書きし（値の検証は呼び出し側の責務）、値が変わったときだけ（作成途中の図形があればそのスタイルも新しい値にしたうえで）1回通知して`true`を返す。`startDraft`が`ShapeFactory.create`の直後に作成途中の図形へ当てる（有無が偽の項目は`null`）。`replaceAllShapes`は触れない（保存・履歴の対象外）。更新は`ShapeStyleEditor`のみ。
    *   **`updateShapeStyles(changes)`**：`changes`＝`[{ id, style: { strokeColor?, strokeWidth?, fillColor? } }]`。各idの図形へ、`style`が自身のプロパティとして持つ3つのキーだけを代入する（値の検証はしない・存在しないidは無視）。1図形以上に代入したときだけ1回通知し、代入した図形の数を返す。選択集合・ホバー・作成途中の図形・直前に使った値には触れない。呼び出し元は`ShapeStyleEditor`のみ。
    *   **知らないこと**：図形固有の頂点構造・内部プロパティ名、図形データ・作業データ形式・`DocumentSerializer`。`Line`への直接依存も持たない。ただし共通プロパティのスタイル3つ（`strokeColor`・`strokeWidth`・`fillColor`）は書く（図形固有のプロパティではない。`updateShapeStyles`・`startDraft`・`updateNewShapeStyle`の作成途中の図形のみ）。
    *   **委譲**：再編集・追従は対象図形の`setVertex`/`translate`/`updateDraftEnd`へポリモーフィックに委譲する。生成は`ShapeFactory.create`へ委譲する。復元は`DocumentSerializer`→`ShapeFactory.fromJSON`が行い、`VectorModel`は復元済みの図形一式を受け取るのみ。
    *   **id**：図形idの採番（形式`shape-<連番>`）は1箇所に一本化する。連番カウンタは単調増加で減らさない。id形式の知識は`VectorModel`内に閉じる（他モジュールはid形式を解釈しない）。単一選択は`setSelection([id])`で表現する。
