*   **VectorModel.js** : 描画データ（Shape配列）と選択集合を保持する単一の真実（SSOT）。選択集合(`#selectedIds`：`Set<string>`)・ホバー状態(`#hoveredId`)・作成中図形(`#draftLine`)・選択矩形(`#selectionRect`)を保持する。選択集合の読み書きAPI（`setSelection(ids)`＝現存idのみで置き換え（単一選択は`setSelection([id])`で表現）/`clearSelection()`/`getSelectedIds()`＝描画順の新しい配列/`isSelected(id)`）、ホバーの読み書きAPI（`setHovered`/`clearHovered`/`getHoveredId`）、選択矩形API（`setSelectionRect(x1, y1, x2, y2)`＝ワールド座標の対角2点を正規化せず保持/`clearSelectionRect()`/`getSelectionRect()`＝コピーまたは`null`）と、ドラフト（作成中図形）のライフサイクルAPI（`startDraft(x, y, type = SHAPE_TYPES[0])`/`updateDraft`/`commitDraft`/`cancelDraft`/`getDraftLine`）を持つ。図形idの採番（形式`shape-<連番>`）はprivate`#issueId()`に一本化し（`commitDraft()`での確定時、`replaceAllShapes()`での振り直し、`addShapesWithNewIds()`での追加時）、連番カウンタ`#nextId`は単調増加で減らさない。id形式の知識は`VectorModel`内に閉じる（他モジュールはid形式を解釈しない）。再編集用の`updateVertex(id, vertexIndex, x, y)`（単一図形）/`moveShapes(ids, dx, dy)`（選択集合等の複数図形の一括平行移動）は、図形固有の頂点構造を意識せず対象shapeの`setVertex(vertexIndex, x, y)`/`translate(dx, dy)`へポリモーフィックに委譲する（`core/`側にshapeの内部プロパティ名を持ち込まない）。図形の生成は`ShapeFactory.create(type, x1, y1, x2, y2)`へ完全委譲する（`Line`への直接依存は持たない）。図形データからの復元は`DocumentSerializer`→`ShapeFactory.fromJSON`が行い、`VectorModel`は復元済みの図形一式を`replaceAllShapes(shapes)`で受け取るのみである（図形データ・作業データ形式・`DocumentSerializer`を知らない）。作成中図形の終点追従を担う`updateDraft(x, y)`は、対象図形の`updateDraftEnd(x, y)`へポリモーフィックに委譲する（追従挙動の詳細は各図形クラス側の責務）。図形の一括削除用の`deleteShapes(ids)`を持ち、削除した図形のidを選択集合・ホバー状態からも同時に除去する（残留防止）。`moveShapes`/`deleteShapes`の変更通知は1操作につき1回（対象が1件以上の場合のみ）で、図形数分は発行しない。
    *   **図形一式の入れ替え** : `replaceAllShapes(shapes)`は全図形を入れ替える。引数の配列はコピーして内部配列とし（引数配列を流用しない）、図形インスタンス自体は複製せずそのまま保持する。idは先頭から順に正規化し、空でない文字列かつそれまでに未出現のidは保持、それ以外（欠落・文字列以外・空文字・重複の後出し）は`#issueId()`で振り直す（受け取ったインスタンスの`id`を直接書き換える）。振り直しの前に、保持した採番形式のidの最大連番より`#nextId`を大きく繰り上げるため、保持idとは衝突しない。入れ替え時に選択集合・ホバー状態・作成中図形・選択矩形をクリアし、変更通知は1回、戻り値は振り直したidの件数。進行中の入力操作は中断しない（呼び出し側が先に`InputTracker.abortOngoingOperation()`を呼ぶ）。idの重複判定はインスタンスではなくidの値で行うため、同一インスタンスを配列に重複して渡さないこと（既存インスタンスを渡す場合は呼び出し側で複製する）。
    *   **新しいidでの追加** : `addShapesWithNewIds(shapes)`は、引数の配列の順に各図形インスタンスの`id`を`#issueId()`で新しいidに上書きして`#shapes`の末尾（最前面）へ追加する（引数の図形のidは引き継がない。`#nextId`は単調増加のため既存図形のidと衝突しない）。引数内で2回目以降に現れるインスタンスと既に`#shapes`にあるインスタンスは、インスタンス参照で判定して`console.warn`のうえ追加しない。追加した図形のidの集合で選択集合を置き換える（ホバー・作成中の図形・選択矩形には触れない）。変更通知は1件以上追加した場合のみ1回、戻り値は追加した図形の新しいidの配列（描画順）。図形インスタンスには`id`の代入以外で触れない。受け取ったインスタンスをそのまま保持して`id`を書き換えるため、呼び出し側は追加後にそのインスタンスを他の用途に流用しないこと。前提として呼び出し側が選択モードであることを保証する（選択集合は選択モード以外では空という不変条件のため）。貼り付け・複製・インポート等で図形を追加する場合はこれを使う（既存の`addShape(shape)`はid採番を通らず`#shapes`へ追加するだけの操作で、呼び出し元はない。使わないこと）。
