*   **InputTracker.js** : ユーザー入力（図形作成・選択・範囲選択・本体ドラッグ・ハンドルドラッグ・パン・ズーム。キーはスペースパンのみ）の解釈とModel・ビュー変換への反映、状態依存の操作（一括削除・取消・全選択・進行中操作の中断）の公開、編集操作の開始・確定の通知（注入された記録先へ）、スクリーン座標からワールド座標への変換、およびカーソル形状のフィードバック。図形種別のif/switch分岐は一切行わず、`shape.hitTest(...)`/`shape.hitTestHandle(...)`/`shape.intersectsRect(...)`をポリモーフィックに呼び出すのみとする。ハンドル種別から更新対象`vertexIndex`への解決も`shape.getVertexIndexForHandle(this.activeHandle)`へ委譲する（図形間で頂点数・意味が異なるため、`vertexIndex`規約を`core/`層にハードコードしない）。`document`購読の`keydown`は`Space`（スペースパン）のみを解釈し、ショートカットの解釈は`KeyboardShortcuts`が担う。
    *   **入力状態** : `IDLE`/`DRAWING`/`DRAGGING_HANDLE`/`MOVING_SELECTION`/`MARQUEE_SELECTING`の5状態を持つ状態遷移マシンとして実装する。`IDLE`ではホバー判定・選択・新規作成の開始、`DRAWING`では作成中図形の追従・確定、`DRAGGING_HANDLE`では選択集合内の1図形の頂点ハンドルによる頂点更新、`MOVING_SELECTION`では選択集合の全図形の平行移動（moveハンドル・本体ドラッグ）、`MARQUEE_SELECTING`では範囲選択を扱い、状態に応じて`VectorModel`の対応するAPIを呼び出す（左ドラッグの3状態は押下時点で遷移し、閾値超過の有無は`DragTracker`が保持する）。
    *   **操作モード・図形種別** : 操作モード(`currentMode`: `OperationMode`＝`'select'`/`'create'`/`'pan'`)と図形種別(`currentShapeType`: `SHAPE_TYPES`のいずれか、初期値は`SHAPE_TYPES`の先頭要素)を独立した状態として保持し、定数`OperationMode`/`SHAPE_TYPES`をexportする（`SHAPE_TYPES`の正本は`ShapeFactory.js`であり、`KeyboardShortcuts.js`のimport元を変えないための再export）。`setMode(mode)`で操作モードを切り替える（処理順は「進行中操作の強制中断（`abortOngoingOperation()`と共通のprivate`#abortOngoingOperation()`）→ モード更新 → 選択集合/ホバー状態のクリア → カーソル再評価」）。`setShapeType(type)`で図形種別を切り替える（作成途中の図形のみ破棄、モードは維持）。いずれも未知の値は`console.warn`のうえ無視する。`getMode()`/`getShapeType()`で現在値を読み出せる。図形種別はモード切替でリセットされないため、図形作成モードへ戻ると前回の種別に復帰する。`currentMode`に応じて`handleMouseMove`/`handleMouseDown`/`handleClick`の解釈を排他的に切り替え、作成開始は図形作成モード中のみ行う。
    *   **カーソル形状** : キャンバスのカーソル形状（パン中:`grabbing`／スペース押下中（左ドラッグ中を除く）・キャンバス移動モード:`grab`／作成モード:`crosshair`／選択モードでハンドルドラッグ・選択集合の平行移動中、ハンドル上、選択集合内の図形の本体上:`move`／範囲選択中:`default`／選択集合外の図形上:`pointer`／その他:`default`）を設定する。
    *   **状態依存の公開メソッド** : `isDragging()`（`DragTracker`のセッション中＝パン・左ドラッグ中か。閾値以前を含む）、`deleteSelection()`（受理条件：選択モード・`IDLE`・ドラッグ中でない・選択集合が空でない。受理時`VectorModel.deleteShapes(ids)`で一括削除。削除ボタンと`Delete`/`Backspace`ショートカット（`KeyboardShortcuts`→`main.js`の注入コールバック経由）、切り取り（`ClipboardController.cut()`へ`main.js`が注入）の唯一の削除経路で、呼び出し側は条件を重複判定しない）、`cancelDraftOrClearSelection()`（`Esc`の実体。作成途中の図形の破棄、または選択モードでの選択解除）、`selectAll()`（選択モード・`IDLE`・ドラッグ中でない場合に全図形を選択）。いずれも受理したら`true`を返す。`abortOngoingOperation()`（常に受理。どの操作モード・入力状態からでも呼べ、何も進行していなければ何もしない）は、ドラッグセッション（パン・ハンドルドラッグ・本体ドラッグ・範囲選択。範囲選択は選択矩形を破棄して確定せず、ドラッグ中に反映済みの頂点・位置は残る）と作成途中の図形を中断して`IDLE`へ戻し、最後にカーソルを再評価する。操作モード・図形種別・選択集合・ホバー状態・スペース押下状態は変更しない（クリアは呼び出し側・`VectorModel.replaceAllShapes`の責務）。戻り値は何かを中断したか（`boolean`）。図形一式の入れ替え（`?dev`の復元）と、取り消し・やり直しの前処理（`main.js`の`performUndo`/`performRedo`。ドラッグ中でないことを確認した後に呼び、戻り値で作成途中の図形を破棄したかを判定する）として用いる（中断する対象を増やす場合は`performUndo`の判定を見直すこと）。private`#abortOngoingOperation()`自体はカーソルを再評価しないため、新たにこれを直接呼ぶ場合はカーソルの再評価を忘れないこと。選択モード以外からの全選択は呼び出し側（`main.js`）が先にモードを切り替える（`InputTracker`は`main.js`の関数を呼ばない）。
    *   **編集操作の通知** : コンストラクタの第4引数`editRecorder`（typedef`EditRecorder`＝`{ beginEdit(): void, commitEdit(): boolean }`。実体は`main.js`が注入する`HistoryManager`。省略時は何もしない凍結定数`NO_EDIT_RECORDER`）へ、編集操作の開始・確定を伝える（`HistoryManager.js`はimportしない）。通知箇所は、作成（`handleClick`の`DRAWING`確定：`commitDraft()`の前後）、削除（`deleteSelection()`の受理時：`deleteShapes`の前後。切り取り（`ClipboardController.cut()`）もこの経路で記録される）、左ドラッグ（`MOVING_SELECTION`/`DRAGGING_HANDLE`のときのみ`#onLeftDragStart`で`beginEdit()`してprivateフラグ`#isEditOpen`を立て、`#finishLeftDrag()`の冒頭でフラグが立っていれば`commitEdit()`する。`MARQUEE_SELECTING`では通知しない）。`#onLeftDragStart`の時点で状態が遷移済みであることは「`DragTracker.begin()`が`onStart`を同期的に呼ばない」ことに依存する。`setMode`ではドラッグ中断の確定（`commitEdit()`）が選択集合のクリアより前に行われる。
    *   **当たり分類** : private`#classifyPoint(point)`（ワールド座標）が、選択集合の全図形のハンドル（図形配列の後ろ＝前面優先。`CanvasManager`のハンドル描画順と一致）と、図形の本体（選択集合の図形を優先、同順位は図形配列の先頭）を1回で分類する。この結果をホバー・押下・クリック・カーソルの4箇所で共用し、クリックの解釈にホバー状態を参照しない。
    *   **選択モードの左ボタン操作** : 押下時は当たり分類により、moveハンドル・選択集合内の本体→`MOVING_SELECTION`、頂点ハンドル→`DRAGGING_HANDLE`、空白→`MARQUEE_SELECTING`へ遷移し、選択集合外の本体ではドラッグを開始しない（離した後のclickで判定）。閾値（`DRAG_START_THRESHOLD`＝スクリーン3px）以内で離した場合はclickとして解釈し、ハンドル上→選択集合を維持、本体上→その図形のみの単一選択、空白→全解除とする。閾値を超えて動かした左ドラッグの直後のclickは抑止する。移動量は押下点（ワールド座標）からの差分で計算するため閾値分の移動量は失われず、ドラッグ中のホイールズーム直後もカーソル位置へ追従し直す。範囲選択の確定（矩形の正規化はここ1箇所のみ）・中断時の破棄は3章「範囲選択の流れ」のとおり。
    *   **座標系** : コンストラクタで`ViewTransform`を受け取る（`main.js`が生成・注入）。`getScreenCoordinate(event)`でスクリーン座標（CSSズーム吸収済み）を取得し、`getWorldCoordinate(event)`でワールド座標へ逆変換する。`VectorModel`・当たり判定へ渡す座標はすべてワールド座標であり、当たり判定の許容誤差（`hitTolerance`、スクリーンpx単位）は画面上5px相当をワールド換算して渡す。
    *   **パン** : 中ボタンドラッグ・スペース＋左ドラッグ・キャンバス移動モード（`'pan'`）の左ドラッグで行う。パン状態は`InputState`と直交するprivateフラグ（`#isPanning`）で表現し、`DRAWING`を保持したまま行える（ドラッグセッション中＝左ドラッグ中は開始しない）。パンの追従・終了・中断は`DragTracker`に委譲し（フロートウィンドウ上・ブラウザ外でのボタン解放にも対応）、左ボタンのパン後の`click`は移動の有無によらず抑止する。スペース押下状態は`keyup`・`blur`で解除する。
    *   **DragTrackerの所有** : コンストラクタで`DragTracker`を生成・所有し（スクリーン座標取得関数`getScreenCoordinate`のみを注入）、パン・左ドラッグの開始時に`begin()`へコールバックを渡す。ドラッグセッションは同時に1つのみ。click抑止フラグの所有者は`DragTracker`であり、`InputTracker`は`handleClick`冒頭で消費、`handleMouseDown`冒頭で残留を解除するのみ。キャンバスの`mouseup`は購読しない（終了検知は`DragTracker`へ一元化）。
    *   **ズーム** : キャンバスの`wheel`（`passive: false`）で、カーソル位置中心のズーム（1刻み`WHEEL_ZOOM_STEP`＝約1.1倍、`deltaY`の符号のみで方向を決定）を行う。操作モード・入力状態によらず常に有効。`WHEEL_ZOOM_STEP`はexportし、キーボードショートカットの拡大・縮小（`main.js`）でも同値を共有する。
    *   **テキスト入力中判定** : ヘルパー`isTextInputElement(element)`をexportし、スペースパンとショートカット（`KeyboardShortcuts`）の両方の誤爆防止に用いる。`input`は`type`別に判定し（テキスト系の`type`一覧`TEXT_INPUT_TYPES`に含まれる場合のみ。`checkbox`/`range`/`button`等は対象外）、`textarea`・`contenteditable`はテキスト入力扱い、`select`は対象外。
