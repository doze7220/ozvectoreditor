*   **ItemRowRules.js**：図形の一覧の行の並び（フォルダの入れ子・折りたたみ）と、字下げ・行の見た目・スクロールの対象を決める規則を、状態を持たない関数として提供する（Phase 11-04aで新設。`buildItemRows`は`ItemListRules`から移した。Phase 11-04bで、描き込む先の印を場所の値（`ItemPlaceRules`）から行ごとの見た目（行の印・線・見えない行の印）にした。Phase 11-05で、行に表示・ロックの状態（`visible`・`locked`・`hiddenByAncestor`・`lockedByAncestor`・`hidden`）を足した。流れは`PROJECT_ARCHITECTURE.md`3章28.）。
    *   **公開**：`buildItemRows(items)`・`resolveRowIndent(depth)`・`resolveRowViews({ rows, isSelected, selectedGroupIds, insertMark })`・`resolveRowHighlight(views)`と、typedef`ItemRow`・`RowView`。
    *   **`buildItemRows(items)`** → `ItemRow[]`（見えている行だけ。上から）：並びの後ろの要素から順に、フォルダなら「フォルダの行 → 中身の行（同じ規則）」。折りたたんだフォルダの中身は行にしない（行は無くても、フォルダの行の`shapeIds`・`groupIds`には入る）。隠れている・ロックされている図形・フォルダも行にする（行を消すのは折りたたみだけ）。1回の再帰で作り、表示・ロックの状態は`ItemStateRules.collectItemStates(items)`を1回求めてidで引く（受け継ぐ計算はここに書かない。Phase 11-05）（図形の数×深さ）。引数を書き換えない。`ItemRow`＝`{ id, kind: 'shape'|'group', name（未定なら空文字）, depth, ancestorIds（外側から）, shape（フォルダはnull。図形インスタンスは共有）, shapeIds（図形は[id]、フォルダは中の図形すべて。行の並びの順）, groupIds（フォルダの中のフォルダすべて。図形は[]）, collapsed, isEmpty（`children`が空のフォルダ）, visible（自分の表示が入か）, locked（自分のロックが入か）, hiddenByAncestor, lockedByAncestor, hidden（隠れている）＝Phase 11-05。`ItemStateRules`の`ItemState`の値そのもの。値の無いアイテム・素の図形は表示あり・ロックなし}`。
    *   **`resolveRowIndent(depth)`**：字下げ（px）。1段12px、6段で頭打ち（72px。7段目以降は同じ字下げ）。名前の幅の見積もり＝240−枠1−スクロールバー約17−左右の余白16−サムネイル28−間8−字下げ72≒98px（図形）、フォルダは三角の分（16＋間4）を引いて約78px。どちらも名前が読める。
    *   **`resolveRowViews({ rows, isSelected, selectedGroupIds, insertMark })`** → 行ごとの`RowView`＝`{ id, kind, name, indent, collapsed, canToggle（空でないフォルダ）, selected, selectedInGroup, insertTarget, insertLine, hiddenMark, visible, locked, hiddenByAncestor, lockedByAncestor, hidden }`（末尾の5つはPhase 11-05。行の値をそのまま渡し、目・鍵・行のうすい見た目の材料にする。`ItemListPanel`が`item-hidden`・目の`is-off`・`is-inherited`・鍵の`is-on`・`is-inherited`のクラスで表す。`13_palette.md`）。`insertMark`は描き込む先の印（場所または`null`。`InsertTargetRules.resolveInsertMark`の結果。旧`insertMarkId`は図形のidだったが、Phase 11-04bで場所へ変えた）。`selectedInGroup`＝上のフォルダのどれかが選ばれている（図形・フォルダとも。弱い見た目）。`selected`＝`selectedInGroup`でなく、図形なら`isSelected(id)`、フォルダなら`selectedGroupIds`にある（強い見た目）。**描き込む先の印の割り当て**は非公開の`resolveInsertMarkEffects`の1か所にまとめてある（行ごとに二重に書かない）：`above`＝`id`の行が見えていて、図形なら`insertTarget: true`（行の印）、フォルダならその行に`insertLine = { edge: 'before', indent: resolveRowIndent(row.depth) }`（フォルダ行の上に出す線＝そのフォルダのすぐ上へ入る）／`inside`＝`id`の行が見えていれば`insertTarget: true`（折りたたんでいても同じ）／`bottom`・`id`が`null`＝最後の行に`insertLine = { 'after', 0 }`（いちばん外側の一番下）／`bottom`・フォルダの行が見えている＝空（`isEmpty`）なら`insertTarget: true`、折りたたんでいれば`hiddenMark: true`、開いていて中身があれば`ancestorIds`にそのフォルダを含む**最後の行**に`insertLine = { 'after', resolveRowIndent(フォルダのdepth + 1) }`（フォルダの中の一番下）／`id`の行が見えていない＝`collapsed`の行のうち`shapeIds`か`groupIds`に`id`を含む行に`hiddenMark: true`（見えている折りたたんだ行は外側の1つだけ）。`insertTarget`は`insertLine`と同時には付かない。**見えない行の印`hiddenMark`**：閉じているフォルダの行で、その中の図形に選ばれているもの・中のフォルダに選んでいるフォルダがあるとき、または上の描き込む先の割り当てで付けられたときに真（自分が選ばれていても出す。見えている外側の閉じたフォルダにだけ出る）。`selectedGroupIds`は`Iterable`で受ける。`insertLine`＝`{ edge: 'before'|'after', indent }`または`null`（`ItemListPanel`がクラス`insert-line-before`／`insert-line-after`とカスタムプロパティ`--insert-line-indent`で表す。`index.html`の`01_index_html.md`）。
    *   **`resolveRowHighlight(views)`** → `{ selectedIds, markId, indexes }`：`selectedIds`＝`selected`か`selectedInGroup`の行のid、`markId`＝`insertTarget`・`insertLine`・`hiddenMark`のいずれかを持つ最初の行のid（無ければ`null`）、`indexes`＝スクロールの対象の添字（`selectedIds`の行。1つも無ければ`markId`の行）。既存の`ListScrollRules.hasHighlightChanged`・`resolveSelectionScrollTop`へ渡す（`ListScrollRules`は変えていない）。
    *   **ホバー**：`resolveRowHover`の`queryExists`（図形だけを見る）がフォルダのidで偽になり、今の規則のまま`clear`になる（変更なし）。
    *   **読むもの**：渡された入れ子の`kind`・`name`・`children`・`collapsed`と、`itemIdOf`の結果だけ。importは`core/ItemTreeRules`（`ITEM_KIND`）・`core/GroupTreeRules`（`itemIdOf`）・`core/ItemPlaceRules`（`PLACE_KIND`）・`core/ItemStateRules`（`collectItemStates`。Phase 11-05）のみ。`visible`・`locked`の値は読まない（`ItemStateRules`が決めた状態を受け取る）。

    *   **使う側**：`wiring/ItemListWiring`（`sync`・行のクリック・三角・行のドラッグの`getRows`・サムネイルの描画）・`core/ListDragRules`（`resolveRowIndent`。線の字下げ）。
    *   **重さ**：同期は1フレームに1回（`ItemListWiring.#requestSync`）、行の組み立ては1回。パネルは変わった行だけDOMへ書く。フォルダの行のサムネイルは描かない。
